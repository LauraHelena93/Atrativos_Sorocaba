## 🌳 Parques e Atrativos Turísticos de Sorocaba

Projeto desenvolvido com HTML e CSS apresentando alguns dos principais parques e pontos turísticos da cidade de Sorocaba.

## 📌 Sobre o projeto

Praticar conceitos fundamentais de desenvolvimento front-end e evolução na criação de interfaces web modernas.

- Framework
- Estruturação HTML;
- Estilização com CSS externo;
- Criação de cards;
- Grid Layout;
- Hover effects;
- Organização visual;
- Responsividade básica.

---

## 🖼️ Funcionalidades

✔️ Cards com imagens padronizadas  
✔️ Efeito hover nas imagens  
✔️ Layout em grid  
✔️ Cabeçalho estilizado  
✔️ Estrutura organizada em seções  
✔️ Footer personalizado
